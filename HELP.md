## Common Questions

### Q: Can I use this on mainnet?
**A:** No. This is a testnet demonstration only. See SECURITY.md for why.

### Q: Where can I get testnet ETH?
**A:** Visit [Sepolia Faucet](https://www.alchemy.com/faucets/ethereum-sepolia)

### Q: How do I change the reward rate?
**A:** Use `setRewardRate()` in the contract (owner only). Rate is in basis points (10 = 0.1%).

### Q: Is this audited?
**A:** No. This is educational code. See SECURITY.md for full details.

### Q: Can I fork this for production?
**A:** Yes, but you must:
- Get professional security audit
- Remove all disclaimers only after audit
- Change branding/naming
- Implement proper governance
- Comply with regulations

## Reporting Issues

### Bugs
1. Search existing issues first
2. Provide reproduction steps
3. Include browser/Node version
4. Attach screenshots if applicable

### Security Issues
⚠️ **Never open public security issues**
- Email security details privately
- Include description, impact, fix suggestion
- Allow 30 days for response
